Krowi's Brokers [System] is a comprehensive system performance monitor for World of Warcraft, displaying real-time FPS, latency, bandwidth, and addon resource usage through your DataBroker display.

### FPS Monitoring
Track your game performance with current, minimum, maximum, and average FPS statistics. Customizable decimal places and color-coded thresholds help you identify performance issues at a glance. Adaptive thresholds automatically adjust based on your max FPS settings.

### Network Statistics
Monitor your connection with home and world latency (ping) measurements, plus incoming and outgoing bandwidth usage. Perfect for diagnosing connection issues during raids or competitive gameplay.

### Addon Resource Tracking
View memory and CPU usage for all installed addons. Sort by name, memory, memory increase, CPU, or CPU increase to identify resource-hungry addons and optimize your game performance. Toggle between ascending and descending sort order.

### Interactive Controls
- **Left-Click**: Trigger garbage collection to free up memory
- **Ctrl+Shift+Left-Click**: Toggle CPU profiling (requires UI reload)
- **Right-Click**: Access settings menu
- **Tooltip Modifier Keys**: Hold Shift/Alt/Ctrl to toggle memory/CPU/increase display in tooltip

### Configuration
- **Flexible Display Options**: Show or hide any stat, with customizable labels and decimal precision
- **Color Coding**: Performance thresholds automatically highlight issues with intuitive color indicators
- **Organized Menus**: Settings organized into logical submenus (FPS, Latency, Bandwidth, AddOn)
- Right-click the broker button to access all settings quickly

### Compatibility
Works with any DataBroker display addon:
- Bazooka
- ChocolateBar
- Titan Panel
- Fortress
- And more!
